POWER BI MODEL

The same engine, served as a Power BI report. When the report is published to the web from Power BI Service, its embed URL goes in the box below (or in POWERBI_EMBED_URL at the top of this page's script) and it renders here. Until then the neon HTML dashboard stands in — it is computed from the identical data.

Report

Publish the report in three steps

  1. Build the report in Power BI Desktop from the kit below (≈20 minutes; BUILD_GUIDE.md has the exact page layout and every measure).
  2. Publish to Power BI Service → open the report → File → Embed report → Publish to web (public) → copy the link that starts with https://app.powerbi.com/view?r=.
  3. Paste it above, or set POWERBI_EMBED_URL in docs/powerbi.html and push — every visitor then sees the live report. (Publish-to-web makes the report public; the data here is illustrative, so that is fine.)
